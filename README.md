# 클로드 펫 (Claude Pet)

바탕화면에 상주하며 **Claude Code 세션 알림을 말풍선으로 전해 주는 데스크톱 펫**(Windows).

터미널을 보고 있지 않아도 된다. 세션이 응답을 마치거나(Stop) 입력·권한을 기다리면
(Notification) 펫이 폴짝 뛰며 **어느 세션인지 이름과 함께** 말풍선을 띄운다.

화면 가장자리와 **열려 있는 창의 위·아랫변에 달라붙어** 그 창을 따라다닌다. 창 위에
앉히면 빵을 먹거나 책을 읽고, 가끔 좌우로 걸어 다니며, 오래 조용하면 눕고 잠든다.

## 필요한 것

- Windows 10/11
- Python 3.10+ (`Pillow`, `numpy`)
- Claude Code

## 설치

```powershell
git clone https://github.com/littlesage/claude-pet.git
cd claude-pet
powershell -ExecutionPolicy Bypass -File install.ps1
```

설치 스크립트가 의존 패키지를 넣고, 아이콘을 만들고, 바탕화면·시작 프로그램 바로가기를
두고, `~/.claude/settings.json`에 알림 훅(Notification·Stop)을 등록한다. 기존 설정은
`settings.json.bak`으로 백업된다. **훅은 새로 시작하는 Claude Code 세션부터 적용된다.**

바탕화면의 **클로드 펫**을 실행하면 오른쪽 아래 작업표시줄 위에 나타난다.
제거는 `uninstall.ps1`(바로가기 삭제 + 훅 해제).

직접 설정하려면 `~/.claude/settings.json`의 `hooks.Notification`과 `hooks.Stop`에
`python <경로>/pet_hook.py notification` / `... stop`을 추가하고 `ClaudePet.bat`으로
실행하면 된다.

## 구조

```
Claude Code hook (Notification/Stop)
  → pet_hook.py  (stdin JSON → events.jsonl append)
  → pet.pyw      (events.jsonl tail → 말풍선 표시)
```

말풍선에는 세션 이름이 함께 표시된다 — `[밸런스 스튜디오] 응답이 끝났어요!` 처럼.
이름은 `/rename`으로 붙인 커스텀 제목을 우선 쓰고, 없으면 CLI 탭 이름(`~/.claude/sessions/<pid>.json`의
`name`)을 쓴다. 둘 다 없으면 작업 폴더명으로 대체한다(홈 디렉토리는 생략).

- `pet.pyw` — 펫 본체. tkinter 투명 오버레이(클릭 통과), 항상 위, 프레임 없음.
- `pet_hook.py` — 훅 수신기 + 세션 이름 해석. `~/.claude/settings.json`의 hooks에서 호출됨.
- `ClaudePet.bat` — 펫 실행 (pythonw, 콘솔창 없음). 중복 실행은 포트 가드(48620)로 자체 방지.
- `events.jsonl` — 이벤트 큐 파일. 펫은 시작 시점 이후 것만 읽음.
- `config.json` — 위치/소리/외형 설정 (자동 저장).
- `assets/` — 펫 외형 이미지. 비어 있으면 내장 벡터 펫을 그린다.
- `assets_sample/` — 규격 참고용 샘플 3종.

## 세션 질문 보드

같은 훅 파이프라인을 재활용하는 애드온. 답을 기다리는 세션이 **무엇을 묻고 있는지**를
한 줄 요약 카드로 모아 보여준다.

```
events.jsonl (stop/notification)
  → question_board.py  (tail → 세션 마지막 메시지 → haiku 요약)
  → questions.json 저장 + events.jsonl에 말풍선 이벤트 append (펫이 표시)
  → 웹 보드 http://127.0.0.1:8620
```

- `question_board.py` — 보드 서버. 요약은 `claude -p --model haiku`를 훅 없이 1회 호출한다.
- `QuestionBoard.bat` — 콘솔에서 실행 + 브라우저 열기.
- `QuestionBoardSilent.vbs` — 창 없이 기동. 시작프로그램에는 이 파일의 바로가기를 둔다.
- `questions.json` — 요약 카드 저장소 (자동 생성).

카드에 선택지가 있으면 클릭해서 복사할 수 있다. **답장은 보드에서 보내지 않는다** —
현재 CLI에 실행 중인 세션으로 입력을 넣는 공식 경로가 없어서, v1은 읽기 전용이다.
답장은 agent view(백그라운드 세션)나 해당 터미널에서 한다.

## 조작

| 동작 | 효과 |
|---|---|
| 드래그 | 위치 이동. 놓으면 가까운 곳에 착 붙는다 (아래 참고) |
| 좌클릭 | **알림이 떠 있으면 그 세션의 터미널 창으로 이동** / 없으면 폴짝 |
| 우클릭 | 메뉴: 테스트 알림 · 소리 켬/끔 · 산책 켬/끔 · 알림 지우기 · 이미지 다시 읽기 · 종료 |

## 미확인 알림 뱃지

말풍선은 12초 뒤 사라지지만 **알림은 클릭할 때까지 사라지지 않는다.** 자리를 비운 사이
쌓인 것을 놓치지 않도록, 몸 오른쪽 위에 빨간 뱃지가 남는다.

| 뱃지 | 뜻 |
|---|---|
| `!` | 한 곳에서 부름 |
| `3` | **세 세션**에서 부름 (건수가 아니라 세션 수를 센다) |
| `9+` | 열 곳 넘음 |
| 진한 빨강 | 그중 **입력을 기다리는 세션**이 있음 — 방치하면 작업이 멈춘 채다 |

한 세션이 여러 번 불러도 뱃지는 하나로 센다. 몇 건이 왔는지보다 **몇 군데가 나를
기다리는지**가 움직일 이유이기 때문이다.

**클릭하면 한 건씩 확인된다.** 뱃지만 있을 때 누르면 먼저 내용을 말풍선으로 보여주고,
한 번 더 누르면 그 알림을 확인 처리하면서 해당 세션 창으로 데려간다. 다음 알림이 있으면
이어서 뜬다. 시간이 지나 말풍선이 저절로 사라지는 것은 확인으로 치지 않는다.
한꺼번에 지우려면 우클릭 → **알림 모두 지우기**.

### 알림을 클릭하면 그 세션으로

말풍선이 떠 있을 때 펫을 클릭하면 **그 알림을 보낸 세션의 터미널 창이 앞으로 나오고,
창 둘레에 테두리가 잠깐 빛난다.** 창이 여러 개 겹쳐 있어도 어느 것이 열렸는지 바로 보인다.
세션 이름이 곧 창 제목이라 이름으로 찾아간다(`find_session_window`). 창을 못 찾으면
아무 일도 일어나지 않고 말풍선만 넘어간다.

테두리는 0.9초 머물다 서서히 사라지며, 마우스를 통과시키므로 클릭을 가리지 않는다.
굵기·시간은 `HL_WIDTH` `HL_MS` 로 조절하고, 끄려면 `config.json`에
`"click_highlight": false` 를 넣는다.

여러 세션을 한 터미널의 탭으로 쓰는 경우에는 창까지만 이동한다 — 탭 단위로 전환하는
공개 API가 없어서다. 이 동작이 싫으면 `config.json`에 `"click_focus": false` 를 넣으면 된다.

## 마그넷 스냅

펫은 떠다니지 않는다. 드래그해서 놓으면 70px 안에 있는 곳에 달라붙는다.

| 놓은 자리 | 결과 |
|---|---|
| 화면 아래 | 작업표시줄 위에 선다 |
| 화면 좌·우·위 | 그 가장자리에 붙는다 (위쪽은 매달린 모습) |
| 창의 윗변 | 그 창 위에 올라앉는다 |
| 창의 아랫변 | 그 창에 매달린다 |
| 아무 데도 아님 | **아래로 떨어진다** (아래 참고) |

### 허공에 놓으면 떨어진다

붙을 곳이 없는 자리에 놓으면 중력을 받아 아래로 떨어지고, 먼저 만나는 표면에 착지한다 —
아래에 창이 있으면 그 창 윗변에 걸터앉고, 없으면 작업표시줄 위에 선다. 떨어지는 중에
다시 집으면 낙하가 취소된다. `fall.png`를 넣으면 떨어지는 동안 그 그림이 쓰인다
(없으면 `drag` → `idle` 순으로 대체).

창에 붙은 뒤에는 **그 창을 따라 움직인다.** 창을 옮기면 같이 가고, 창이 닫히거나
최소화되면 작업표시줄 위로 내려온다. 작업표시줄 크기나 해상도가 바뀌어도 5초 안에
다시 정렬한다. 붙는 기준은 캔버스 가장자리가 아니라 **캐릭터의 실제 발끝/머리끝**이라
이미지에 여백이 있어도 붕 뜨지 않는다.

## 펫 외형을 내 이미지로 바꾸기

`assets/` 폴더에 아래 이름으로 넣으면 된다. **`idle` 하나만 있어도 되고**,
넣는 즉시 3초 안에 재시작 없이 반영된다 (급하면 우클릭 → "이미지 다시 읽기").
폴더를 비우면 내장 벡터 펫으로 돌아온다.

### 이미지 적용 방법

1. 새 이미지 파일을 `assets/`에 넣는다.
2. 실행 중인 펫은 3초 안에 자동으로 다시 읽는다.
3. 바로 확인하고 싶으면 펫을 우클릭해서 **이미지 다시 읽기**를 누른다.
4. 기존 상태의 이미지만 바꾼 경우에는 재시작이 필요 없다.
5. 새 상태 이름을 코드에 추가한 경우에는 `ClaudePet.bat`로 펫을 한 번 다시 실행해야 한다.

같은 상태에 여러 확장자가 있으면 코드가 `.gif` → `.png` → `.webp` → `.jpg` 순서로 먼저
찾은 파일을 쓴다. 예를 들어 `idle.png`와 `idle.webp`가 같이 있으면 `idle.png`가 우선된다.
움직이는 idle을 쓰려면 `idle.png`를 빼고 `idle.webp`만 두면 된다.

| 파일 | 언제 쓰이나 | 필수 |
|---|---|---|
| `idle.png` / `idle.webp` / `idle.gif` | 평소 모습 | ✅ |
| `notify.png` | 알림이 온 순간 1.2초 (놀란 표정 등) | 선택 |
| `blink.png` | 눈 깜빡임 0.15초 | 선택 |
| `sit.png` / `sit.webp` | 창 위에 앉아 있을 때 | 선택 |
| `sit_blink.png` | 앉은 상태에서 눈 깜빡임 | 선택 |
| `hang.gif` / `hang.webp` | 화면 위/창 아래에 매달릴 때 | 선택 |
| `lie.png` | 오래 조용할 때 누운 모습 | 선택 |
| `lie_blink.png` | 누운 상태에서 눈 깜빡임 | 선택 |
| `prone.png` | 엎드린 모습 (`lie` 대체 후보) | 선택 |
| `prone_blink.png` | 엎드린 상태에서 눈 깜빡임 | 선택 |
| `sleep.gif` / `sleep.webp` | 더 오래 조용할 때 잠든 모습 | 선택 |
| `walk.gif` / `walk.webp` | 스냅/복귀 이동 중 걷는 모습 (**오른쪽 향해** 그릴 것) | 선택 |
| `fall.png` | 허공에서 떨어지는 중 | 선택 |
| `drag.png` | 드래그 중 잡힌 모습 | 선택 |

확장자는 `.png` `.gif` `.webp` `.jpg` 를 지원한다. **애니메이션 GIF/WebP를
넣으면 프레임 지속시간 그대로 재생**된다 (`idle.gif`나 `idle.webp` 하나로 상시
움직이는 펫이 된다).

### 이펙트는 정렬 기준에서 빠진다

땀방울·반짝임처럼 몸에서 떨어져 있는 작은 장식은 위치 계산에서 제외된다(`body_bbox`).
그렇지 않으면 이펙트가 나타났다 사라질 때마다 중심이 밀려 캐릭터가 좌우로 흔들린다.
실제로 매달리기 그림의 땀방울 때문에 프레임 간 경계가 24px씩 달라지던 것을 이렇게 잡았다.

### 소품(봉 등)은 그리지 않는 편이 낫다

매달리기에 봉을 함께 그렸더니 프레임마다 봉의 두께와 높이가 달라 깜빡였다.
**손만 그리고 소품은 빼는 편이 안정적이다** — 창 가장자리가 곧 잡는 대상이 된다.
이미 그려진 봉은 `python tools_remove_bar.py`로 지울 수 있다(몸통보다 옆으로 넓게
뻗은 가로줄을 찾아 비운다). 그 뒤 `python tools_build_hang.py`로 `hang.webp`를 다시
만든다. 원본은 `hang.webp.bak`으로 남는다.

### 애니메이션은 프레임마다 닿는 지점을 고정한다

매달리기처럼 프레임마다 몸 위치가 흔들리는 애니메이션도, **닿아야 할 지점은 프레임
단위로 고정**된다. 매달린 손은 창 아랫변에 붙은 채 몸만 대롱거리고, 서 있는 자세는
발바닥이 고정된 채 상체만 움직인다. 그러니 숨쉬기·흔들림을 자유롭게 넣어도 된다.

`hang` 계열만 **위쪽(손끝) 기준**으로 붙고 나머지는 아래쪽(발바닥) 기준이다.

### 자세별 알림 반응

알림이 오면 1.2초간 놀라는 그림을 쓰는데, `notify.png`는 **서 있는 자세**다. 그래서
앉아 있거나 매달린 상태에서 알림이 오면 그 1.2초만 서 있는 모습이 나온다.

`sit_notify` `hang_notify` `lie_notify` `prone_notify` 를 넣으면 각 자세에 맞는 반응으로
바뀐다. 없으면 지금처럼 서 있는 `notify`로 대신한다 — 알림은 눈에 띄는 편이 우선이라
깜빡임과 달리 자세 유지보다 알림 그림을 앞세운다.

### 자세별 눈 깜빡임

깜빡일 때는 **그 자세에 맞는 눈감은 그림**을 먼저 찾는다. `<자세>_blink` 규칙이라
`sit_blink` `lie_blink` `prone_blink` `hang_blink` 를 넣으면 각각 물린다.
해당 파일이 없으면 서 있는 `blink`로 갈아타지 않고 **눈 뜬 그대로 그 자세를 유지**한다 —
자세가 맞는 편이 눈을 감는 것보다 덜 어색하기 때문이다. 잠든 자세(`sleep`)는 이미
눈을 감고 있으므로 깜빡임을 찾지 않는다.

### 앉아서 하는 행동 (sit_actions)

창에 앉아 있을 때 18~40초마다 짧은 행동을 한 번씩 한다(빵 먹기, 다리 흔들기, 팻말,
게임, 독서, 졸기). 리소스는 `assets/sit_actions/<행동>/*.png`, 재생 순서와 간격은
같은 폴더의 `actions.json`에 있다. 알림·드래그·창 이탈 시 취소되고, 우클릭 →
**앉기 모션 끄기**로 막을 수 있다.

**행동 그림을 새로 뽑을 때 주의할 점 두 가지.**

1. **크로마키 색을 캐릭터에 없는 색으로 쓸 것.** 민트 배경으로 뽑으면 민트 치마가
   배경으로 인식돼 잘려 나간다. 실제로 그 탓에 치마 밑단이 사라져 다리가 몸통에서
   분리되고 치마에 구멍이 남았다. 마젠타처럼 캐릭터에 전혀 없는 색을 쓰면 안전하다.
2. **프레임마다 캐릭터 위치가 달라도 된다.** 코드가 프레임별로 위치를 맞춰 그리므로
   화면에서는 고정돼 보인다. 다만 자동 생성 그림은 위치가 크게 흔들리는 편이니
   (실측 평균 18px, 최대 43px) 되도록 같은 구도로 뽑는 편이 결과가 낫다.

### 가끔 거닐기

서 있거나 창에 앉아 있을 때 **45~150초에 한 번씩** 좌우로 걸어 다닌다. 한 번에 걷는
시간은 **0.8~3.0초 사이에서 무작위**(`WANDER_TIME`)로 정해지고, 속도는 초당 160px
(`WANDER_SPEED`)이라 거리로는 128~480px이 된다. 걸음 애니메이션 한 사이클에 약 77px을
가므로 발이 미끄러지지 않는다.

걷는 동안에는 `walk` 그림이 쓰인다. 바닥에서는 작업영역 안, 창 위에서는 그 창의 폭
안에서만 움직이므로 화면 밖이나 창 밖으로 나가지 않는다.

알림이 오거나 펫을 집으면 즉시 멈춘다. 매달린 상태이거나 누워 있을 때(5분 이상 조용)는
거닐지 않는다. 성가시면 **우클릭 → 산책 끄기**로 멈출 수 있다(`config.json`의 `wander`).

### 앉아서 하는 짧은 행동

창 위에 앉아 있으면 18~40초 간격으로 아래 행동 중 하나를 골라 한 번 재생하고
`sit.png`로 돌아온다.

- 빵 꺼내 먹기
- 다리 번갈아 흔들기
- `오늘도 힘내세요` 팻말 쓰고 들기
- 휴대용 게임기로 게임하기
- 책 꺼내 읽기
- 꾸벅꾸벅 졸다가 깨기

PNG 프레임은 `assets/sit_actions/<행동>/`에 있고, 재생 순서·프레임 유지시간·선택
가중치는 `assets/sit_actions/actions.json`에서 정한다. 같은 PNG를 여러 번 적으면
이미지를 복제하지 않고 왕복 동작을 만들 수 있다. 프레임이나 JSON을 바꾸면 하위 폴더까지
감지해서 3초 안에 다시 읽는다.

**한 구간을 되풀이하려면 `repeat`를 쓴다.** 책을 읽거나 게임을 하는 '하는 중' 구간을
길게 보여줄 때 쓴다. 아래는 펼친 다음 읽는 동작을 4번 되풀이하고 덮는 예다.

```json
"sequence": [
  ["01.png", 350],
  ["02.png", 400],
  {"repeat": 4, "frames": [["03.png", 700], ["04.png", 650]]},
  ["05.png", 350],
  ["06.png", 900]
]
```

현재 독서는 7.4초, 게임은 4.5초로 잡혀 있다. 더 길게/짧게 하려면 `repeat` 숫자만
바꾸면 된다. 지속시간을 손으로 고쳐 25의 배수에서 어긋났을 때는
`python tools_snap_durations.py`로 맞추고, JSON 모양이 흐트러지면
`python tools_tidy_actions.py`로 정리한다.

행동 중 알림이 오거나 펫을 집거나 창에서 내려오면 즉시 취소된다. 성가시면
**우클릭 → 앉기 모션 끄기**로 멈출 수 있다(`config.json`의 `sit_actions`).

기본 앉기 자세는 `sit.webp`의 6프레임 미세 호흡 루프다. 엉덩이·다리·손은 고정하고
상체 높이만 1~2px 변한다. 원본 정지 이미지는 `sit_base.png`, 개별 확인 프레임은
`sit_idle_frames/`에 보관한다. 다시 만들려면 `python tools_build_sit_idle.py`를 실행한다.

### 조용할 때 (눕기 · 자기)

5분간 조용하면 눕고(`lie`), 20분이면 잠든다(`sleep`). **단 바닥에 서 있을 때만이다** —
창에 앉았거나 매달린 상태에서는 허공에 드러눕게 되므로 그 자세를 유지한다.

앉거나 매달린 채로 조는 그림을 넣고 싶으면 `sit_sleep` `hang_sleep` 을 추가하면 된다.
20분이 지나면 자동으로 물리고, 없으면 지금처럼 그냥 그 자세로 있는다.

### 포즈 리소스 발주 가이드

여러 포즈를 한꺼번에 맡길 때 **이것만 지키면 나머지는 코드가 알아서 맞춘다.**

1. **모든 포즈를 같은 캔버스에 그린다.** 예: 전부 512×512.
   포즈마다 캔버스가 다르면 크기가 제각각으로 표시된다.
2. **바닥선은 대충 맞아도 된다.** 코드가 각 포즈의 알파 경계를 재서 서 있는 자세의
   발바닥 선에 자동으로 맞춰 그린다(`_align`). 눕기처럼 캔버스 안에서 몸이 떠 있어도
   바닥에 닿게 보정된다. 다만 **의도적으로 띄운 포즈(점프 등)도 바닥에 붙으므로**
   그런 동작이 필요하면 따로 알려줄 것.
   - `hang`(매달리기)은 머리 꼭대기가 창 아랫변에 닿는다. 서 있는 자세와 머리 높이를
     비슷하게 맞춰 그리면 된다.
   - `sit`(걸터앉기)은 발끝이 아니라 **엉덩이 선**이 창 윗변에 닿는다. 그 선은 몸통이
     끝나고 늘어뜨린 다리만 남는 높이를 재서 자동으로 잡는다. 어색하면 `config.json`에
     `"sit_anchor": 0.75` 처럼 0~1 비율을 넣어 직접 지정할 수 있다(0=머리, 1=발끝).
3. **가로 중심도 자동 보정된다.** 그래도 크게 어긋나지 않게 그리는 편이 안전하다.
4. **`walk`은 오른쪽을 향해 걷는 모습으로 그린다.** 왼쪽으로 갈 때는 코드가 좌우로
   뒤집어 쓴다(`DIRECTIONAL`). 다른 자세는 정면이면 되고 반전하지 않는다.
5. 반투명 금지 — 아래 이미지 규격 참고.

정지 이미지로 발주해도 전부 동작한다. 나중에 같은 이름의 `.gif`/`.webp`로 바꿔 넣기만
하면 애니메이션으로 승격되므로, **처음부터 전 포즈를 애니메이션으로 만들 필요는 없다.**

움직임이 실제로 필요한 포즈는 다음 셋 정도다.

| 포즈 | 애니메이션 필요성 |
|---|---|
| `idle` | ⭐ 가장 오래 보이는 모습. 숨쉬기·꼬리 흔들기 정도만 있어도 살아 보인다 |
| `walk` | ⭐ 정지 이미지면 미끄러지듯 이동해 어색하다 |
| `sleep` | 있으면 좋음 (숨쉬기) |
| 나머지 | 정지 1장으로 충분. `notify`는 1.2초, `blink`는 0.15초만 보인다 |

애니메이션 포맷은 **`.webp`(풀컬러 + 알파)를 권장**한다. `.gif`는 256색으로 줄어들어
그라데이션이 뭉갠다. 프레임은 4~12장, 마지막에서 첫 장으로 자연스럽게 이어지게(루프)
만들면 된다.

**프레임 지속시간은 25의 배수로 맞출 것.** 화면을 25ms마다(40fps) 다시 그리므로,
지속시간이 어긋나면 어떤 프레임만 한 틱 더 머물러 떨리는 것처럼 보인다.
100ms(4틱)나 125ms(5틱)가 무난하다.

### 이미지 규격

- **크기**: 정사각 256~512px 권장. 화면에는 긴 변 기준 150px로 자동 축소된다
  (`config.json`의 `sprite_size`로 조정. 예: `"sprite_size": 200`).
  축소는 premultiplied alpha로 처리하므로 가장자리에 어두운 테두리가 번지지 않는다.
- **배경**: 완전 투명 PNG.
- **⚠ 반투명 금지**: 알파 50% 미만 픽셀은 잘려 나가고, 그 이상은 100% 불투명으로
  처리된다. 그래서 **드롭섀도우·글로우·반투명 유리 효과는 지저분한 얼룩으로 남거나
  통째로 사라진다.** 그림자를 넣고 싶으면 불투명한 색으로 그릴 것.
  가장자리 안티에일리어싱은 정상 동작하니 신경 쓰지 않아도 된다.

반투명이 잘리는 이유는 Windows 오버레이가 `-transparentcolor` 방식이라 특정 키색
(마젠타 `#ff00fe`)과 정확히 일치하는 픽셀만 뚫기 때문이다. 반투명 픽셀을 키색과
알파 블렌딩하면 가장자리에 분홍 테두리가 남으므로, 알파를 임계값으로 이진화한다.
임계값은 `config.json`의 `alpha_threshold`(0~255, 기본 128)로 바꿀 수 있다 —
낮추면 옅은 영역까지 살아나지만 얼룩이 생기고, 높이면 실루엣이 얇아진다.

## 실행 아이콘

바탕화면의 **클로드 펫** 바로가기로 실행한다. 아이콘은 `make_icon.py`가 `assets/`의
펫 그림에서 만든 `ClaudePet.ico`(16~128px 7종)이다. 캐릭터를 바꾼 뒤 아이콘도 새로
뽑으려면 `python make_icon.py`를 다시 돌리면 된다(바로가기는 그대로 두면 된다).

## 부팅 시 자동 시작

시작 프로그램에 등록되어 있어 로그인하면 자동으로 뜬다
(`shell:startup`의 `ClaudePet.lnk`). 빼려면 그 바로가기를 지우면 된다.

## 훅 설정

`~/.claude/settings.json`의 `hooks.Notification` / `hooks.Stop`에
`python pet_hook.py <type>` 커맨드가 등록되어 있다. 훅 변경은 새 세션부터 적용된다.
